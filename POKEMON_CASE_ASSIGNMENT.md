# Pokemon Case

## Task

Your task is to create a small website that helps a user answer the following question:

```text
Should I evolve this Pokemon?
```

The website must be hosted online with GitHub Pages.

When image data is available, each Pokemon should be displayed with its corresponding image.

## Submission Requirements

Submit the following for grading:

- A link to your live website.
- A link to your public GitHub repository.
- A short statement explaining how much time you spent working on the case.
- A short statement explaining how much the work cost.

For the cost statement, include any relevant use of AI tools. For example, if you used a free ChatGPT account, explain approximately how much of your available usage limit you used.
